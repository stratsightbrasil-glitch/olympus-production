packages/core — Motor de IA

Agent.ts
Executa um agente via generateText / streamText.
• TOOL_JSON_SCHEMAS: schemas puros (sem Zod)
• getModel(): Provider Factory (LLM_PROVIDER env)
• stopWhen: stepCountIs(N)
• prepareStep: toolChoice "required" só no step 0
• Fix obrigatório: (tool as any).inputSchema = () => jsonSchema(...)
Orchestrator.ts
Registry de agentes + dispatch por nome.
• registerAgent(agent)
• getAgent(name: string)
• dispatch(name, input, context, vizMode)
Instanciado por chat.ts em cada requisição com os agentes da metodologia ativa.

packages/db — Schema do Banco

Fluxo de Execução Detalhado (chat.ts)

POST /api/v1/chat/stream
  ↓
1. Verificar JWT (middleware Hono)
2. Carregar metodologia do banco (getOrSeedMethodology)
3. Instanciar agentes da metodologia (agentsConfig[] → new Agent())
4. Registrar no Orchestrator
5. Preparar contexto: { projectId, methodology, memory: messages.slice(-12), callbacks }
6. streamText via HERMES
   └── step 0: toolChoice = "required" → HERMES invoca consultar_agente
       └── Orchestrator.dispatch(agentName, query, context)
           └── Agent.run(especialista)
               └── generateText com tools (web_search / buscar_dados_publicos / RAG)
                   └── Claude API → resultado
           └── retorna string para HERMES
   └── steps 1+: toolChoice = "auto" → HERMES sintetiza ou chama outro especialista
   └── stopWhen: stepCountIs(15) → limita loop
7. SSE emite: { type: 'agent', name } | { type: 'token', text } | { type: 'done' }
8. Persistir mensagem no banco (messages.insert)
9. Atualizar projeto (projects.update)

Padrão do Agent.ts (Regra de Ouro)

import { generateText, streamText, jsonSchema, tool, stepCountIs } from "ai";

// NUNCA maxSteps — usar stopWhen
const response = await generateText({
  model: getModel(),  // lê LLM_PROVIDER do env
  system: this.systemPrompt,
  messages,
  tools: hasTools ? aiTools : undefined,
  stopWhen: stepCountIs(15),
  prepareStep: hasTools
    ? async ({ stepNumber }) => ({ toolChoice: stepNumber === 0 ? "required" : "auto" })
    : undefined,
  maxTokens: 32000,
});

// Fix OBRIGATÓRIO — sem isso execute() nunca é chamado:
(myTool as any).inputSchema = () => jsonSchema(rawSchema as any);
